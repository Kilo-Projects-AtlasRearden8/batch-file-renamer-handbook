01 · Safety first

Before you rename a single file, read this page. Batch renaming is fast — and mistakes are fast too. One wrong command can rename a hundred files in a second, and most tools have no built-in "undo."

The golden rules

  1. Test on copies, never originals. Copy your folder to a new folder (or a USB stick) and practice there first. Only rename the real files when the copy worked exactly as expected.
  2. Never move originals. The tools here rename files in place; they do not move them to another drive or delete them. You shouldn't either, while learning.
  3. Use preview (dry-run) mode first. Every tool shows what would happen without changing anything. Always preview first.
  4. Keep an undo log. A good batch rename writes down every old name and every new name so you can reverse it exactly, file by file.
  5. Rename one type of file at a time. It is easier to spot mistakes when all the files look alike.
  6. Close the files first. Close any open documents, photos, or spreadsheets before renaming them.
MistakeWhat happensHow to avoid it
Renaming originals instead of copiesOriginal names are lostCopy the folder first; practice on the copy
A pattern matches too many filesFiles you meant to skip get renamedPreview first; narrow the pattern
A typo in the replacement textAll files get the same typoPreview first; check the list carefully
No undo log keptYou cannot reverse the renameUse tools that write an undo log
Renaming open filesErrors or confused programsClose all files before renaming

Remember: there is no shame in testing on copies. The people who lose files are the people who skip this step.

02 · Built-in tools

You do not need to install anything to start batch renaming. Every computer comes with tools that can do it.

Windows — File Explorer (easiest, safest for beginners)

  1. Open the folder with your files.
  2. Select the files: Ctrl+A for all, or hold Ctrl and click to pick several. Click the first, hold Shift, click the last to select a range.
  3. Right-click and choose Rename (or press F2).
  4. Type the new name and press Enter.

Windows renames the first file to exactly what you typed, and numbers the rest: vacation.jpg, vacation (1).jpg, vacation (2).jpg…

Undo: press Ctrl+Z right after renaming. This only works for renames done inside File Explorer, and only immediately after.

Windows — PowerShell (more control)

# Preview only — shows what would happen, changes nothing
Get-ChildItem *.jpg | ForEach-Object { $_.Name, $_.BaseName + "-copy" + $_.Extension }

# Apply — add a prefix to every .jpg file
Get-ChildItem *.jpg | Rename-Item -NewName { "trip-" + $_.BaseName + $_.Extension }

Safety tip: run the preview version first. When the list looks right, run the rename command. PowerShell does not keep an undo log by default.

macOS — Finder

  1. Open the folder in Finder.
  2. Select the files (Cmd+A for all, or hold Cmd and click).
  3. Right-click (or Ctrl+click) and choose Rename X Items.
  4. Choose Replace Text, Add Text (before or after the name), or Format (same name with numbers).
  5. Click Rename.

Undo: press Cmd+Z immediately after renaming (Finder only).

macOS / Linux — Terminal (mv)

# Rename one file
mv "old-name.jpg" "new-name.jpg"

# Preview first: echo shows what would happen
for f in *.jpg; do echo "mv \"$f\" \"trip-$f\""; done

# Then apply (remove the echo when the preview looks right)
for f in *.jpg; do mv "$f" "trip-$f"; done

Always put file names in quotes ("$f") so names with spaces do not break the command. The Terminal has no undo — test on copies.

03 · Patterns

A pattern tells the computer "only rename files that look like this." Patterns keep you from accidentally renaming files you meant to leave alone.

Wildcards (built into every operating system)

WildcardMeaningExample matches
*Any text, any length*.jpg matches every .jpg file
?Exactly one characterphoto?.jpg matches photo1.jpg, not photo12.jpg
[abc]One of those lettersfile[12].txt matches file1.txt and file2.txt

Regular expressions (regex)

Regular expressions match patterns like "exactly three digits." They look scary but are built from a few simple pieces.

PieceMeaningExample
.Any single charactera.c matches abc, a2c
*Zero or more of the thing before itab* matches a, ab, abb
+One or more of the thing before itab+ matches ab, abb, not a
?Zero or one of the thing before itcolou?r matches color and colour
\dAny digit (0–9)\d\d\d matches 123, 007
^Start of the text^IMG matches names starting with IMG
$End of the text\.jpg$ matches names ending in .jpg
(…)A group you can reuse(\d{4})-(\d{2})-(\d{2})

The backslash before the dot matters: \. means a literal dot. . alone means "any character."

Pattern playground — test before you rename

I want to matchTry this pattern
All PDFs\.pdf$ or *.pdf
Files starting with scan^scan or scan*
IMG_ followed by 4 digits^IMG_\d{4}
Names containing draftdraft
Exactly 3 digits anywhere\d{3}
Names ending in .jpg or .jpeg\.jpe?g$
List first, rename second. Show the list of matching files before changing anything. Start narrow — match too few files rather than too many.

04 · Prefixes

A prefix is text added to the front of a file name:

invoice-2026-10.pdf
2026-10-invoice-2026-10.pdf
          ↑ prefix added

Prefixes are useful for grouping files, sorting them together, or marking their status (draft-, final-, archive-).

Built-in tools

  • File Explorer / Finder: select the files, rename the first one with your prefix (e.g. trip-1.jpg), and the OS numbers the rest.
  • PowerShell: Get-ChildItem *.jpg \| Rename-Item -NewName { "trip-" + $_.BaseName + $_.Extension }
  • macOS Finder: Rename Items → Add Text → "Before name" → type your prefix → Rename.
  • Terminal: for f in *.jpg; do mv "$f" "trip-$f"; done

With scripts/rename.py

# Add a prefix
python3 scripts/rename.py --path ./my-copies --prefix trip- --apply
# photo.jpg → trip-photo.jpg

# Only .pdf files get the prefix
python3 scripts/rename.py --path ./my-copies --pattern '\.pdf$' --prefix invoice- --apply
Preview first. Combine --prefix with --pattern so only matching files get the prefix. Keep the undo log — if receipt- was the wrong word, you can reverse every rename in one step.

05 · Dates

Adding dates to file names is one of the best ways to keep files sortable. A file named 2026-10-28 receipt.pdf sorts neatly next to 2026-10-29 receipt.pdf in every file browser.

Use the ISO date format: YYYY-MM-DD

Always write dates as four-digit year, two-digit month, two-digit day, for example 2026-10-28.

Why: names starting with 2026-10-28 sort in chronological order everywhere. Formats like 10-28-2026 do not sort correctly. Avoid slashes (2026/10/28) — some operating systems do not allow / in file names.

Add today's date

Built-in tools usually cannot insert today's date automatically — you type it yourself.

# PowerShell
$date = Get-Date -Format "yyyy-MM-dd"
Get-ChildItem *.jpg | Rename-Item -NewName { "$date-" + $_.BaseName + $_.Extension }

# macOS / Linux Terminal
today=$(date +%F)   # gives 2026-10-28
for f in *.jpg; do mv "$f" "${today}-$f"; done

With scripts/rename.py

# Add today's date to every file
python3 scripts/rename.py --path ./my-copies --date-prefix --apply
# photo.jpg → 2026-10-28-photo.jpg

# Only PDFs
python3 scripts/rename.py --path ./my-copies --pattern '\.pdf$' --date-prefix --apply
One date per run. All files renamed in a single --date-prefix pass get today's date. Date-stamp copies first.

06 · Undo precautions

Undo is the most important part of batch renaming. Every tool has limits on what it can reverse. Know them before you start.

ToolUndo methodLimits
Windows File ExplorerCtrl+Z immediately afterFile Explorer renames only; most recent action
macOS FinderCmd+Z immediately afterFinder renames only; most recent action
PowerShell Rename-ItemNo built-in undoReverse each rename by hand
Terminal mvNo built-in undoReverse each rename by hand
scripts/rename.pyUndo log written by the scriptReverses exactly what that run did

Dry-run mode — always run it first

scripts/rename.py does nothing unless you pass --apply. Without it, the script only prints what it would do:

python3 scripts/rename.py --path ./my-copies --prefix trip-
# DRY RUN — no files were changed
# photo.jpg   →   trip-photo.jpg

Look the list over. Does every arrow look right? Did any file you wanted to skip appear? Only when the preview looks perfect do you add --apply.

The undo log

Every --apply run writes an undo log like rename-undo-20261028-143022.json. To reverse that run:

python3 scripts/rename.py --undo rename-undo-20261028-143022.json --apply

The script renames every to name back to its from name, in reverse order, and checks each file still has the expected name first.

Before you apply any batch rename:
  • I am working on a copy of my files
  • I ran a preview / dry-run first
  • The preview shows exactly the changes I expect
  • All files to be renamed are closed
  • I know how to undo: Ctrl+Z, Cmd+Z, by hand, or scripts/rename.py --undo
  • I saved the undo log somewhere I can find it

If you cannot answer "yes" to every item, stop and copy your folder first.

07 · Quick reference

Tape this page to your monitor.

Before you start: copy the folder → close all files → preview → apply only when the preview looks right → keep the undo log.

scripts/rename.py

# Preview (changes nothing)
python3 scripts/rename.py --path ./folder --prefix trip-

# Apply
python3 scripts/rename.py --path ./folder --prefix trip- --apply

# Add today's date (YYYY-MM-DD)
python3 scripts/rename.py --path ./folder --date-prefix --apply

# Only files matching a pattern
python3 scripts/rename.py --path ./folder --pattern '\.pdf$' --prefix invoice- --apply

# Undo a previous run
python3 scripts/rename.py --undo rename-undo-*.json --apply

Emergency

  • Renamed the wrong files on a copy? Delete the copy and try again.
  • Renamed originals and have an undo log? Run scripts/rename.py --undo <log-file> --apply.
  • Renamed originals, no log, File Explorer/Finder? Press Ctrl+Z / Cmd+Z right away.
  • Otherwise: rename each file back by hand. That is why we test on copies.
